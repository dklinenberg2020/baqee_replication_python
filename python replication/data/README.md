# Data

`consumption_energy.py` expects a Stata extract at
`data/evs2013_aa_gs_hb.dta` (configurable via `--input`) — the 2013
Scientific Use File of the German EVS (Einkommens- und
Verbrauchsstichprobe). This is restricted-access microdata from the German
Federal Statistical Office, available only under a separate data use
agreement through the research data center:
https://www.forschungsdatenzentrum.de/de/haushalte/evs

It is not, and cannot be, included in this repository. See the main
`README.md`'s section 2 for what has and hasn't been validated without it.
